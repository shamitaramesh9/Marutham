Marutham 🌾
Digital Command Center for Unused Land Management

Project Overview
Marutham is an Agri-Tech platform developed by Team Marutham. The project focuses on a "gig farming" business model designed to help landowners monitor and manage unused land remotely. By turning physical land into a managed digital asset, we aim to ensure no land remains unproductive or unmonitored.

The Vision
24/7 Monitoring: Providing landowners with a dashboard to check property status.

Asset Management: Transforming unutilized land into productive space through a decentralized workforce.

Data-Driven Farming: Preparing for future integration of soil metrics, moisture levels, and land utilization stats.

Technical Implementation
Methodology: Built using vibe coding (AI-assisted development), allowing for rapid prototyping of the core business logic and user interface.

Tech Stack: HTML5, CSS3, and JavaScript.

Status:

Frontend: The framework and user journey (Login & Dashboard) are fully operational and hosted via GitHub Pages.

Backend: Currently in the developing phase.
